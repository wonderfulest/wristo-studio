# 动态图片元素设计

## 背景

Studio 目前通过多个独立 `image` 元素叠放在同一位置，并分别配置动态可见性，来实现天气背景、状态图标等素材切换。该方式可以运行，但会重复维护位置和尺寸，图层数量多，也无法明确表达素材之间“只显示一个”的互斥关系。

本设计新增独立的 `dynamicImage` 元素。它在一个公共画框中维护多个“表达式 → 素材”候选项，运行时按顺序选择并绘制一张图片。

## 目标

- 用一个图层表达同一位置上的动态图片切换。
- 所有候选素材共享位置和宽高，并固定拉伸到公共宽高。
- 按候选项顺序选择第一个表达式成立的素材。
- 未命中任何候选素材时隐藏。
- Studio 预览、设计保存、WRT 打包与 Connect IQ 运行时保持相同语义。
- 不改变现有 `image` 元素或旧设计数据。

## 非目标

首版不支持：

- 将多个已有 `image` 元素批量转换成动态图片。
- 为候选素材设置独立位置、尺寸或缩放模式。
- 同时绘制多个命中的素材。
- 动态图片嵌套动态图片。
- 在候选项中混合图片、文字、图形等不同元素类型。
- 在图层面板中把每个候选素材显示为独立子图层。

## 元素模型

UI 名称为“动态图片”，内部元素类型为 `dynamicImage`。

```ts
interface DynamicImageElementConfig extends BaseElementConfig {
  eleType: 'dynamicImage'
  width: number
  height: number
  items: DynamicImageItem[]
}

interface DynamicImageItem {
  id: string
  imageUrl: string
  assetId?: number
  expression: DynamicExpression<boolean>
}

interface DynamicImageAsset {
  imageUrl: string
  assetId?: number
}
```

候选项数组的存储顺序就是匹配优先级。候选项只能拥有素材和表达式；布局字段只能存在于外层元素。所有候选图片固定使用 `stretch` 语义，强制拉伸到元素公共宽高，不提供缩放模式选项。

## 运行语义

1. 从上到下计算候选表达式。
2. 第一个结果为 `true` 且素材可用的候选项胜出，后续候选项不再计算。
3. 表达式为 `false`、数据不可用或计算异常时，将该项视为不命中并继续下一项。
4. 表达式成立但素材加载失败时，继续查找后续可用的命中项。
5. 没有可用候选项时不绘制元素。

动态图片不提供元素级动态可见性编辑入口；Active/AOD 显示状态仍沿用所有元素共有的显示状态能力。

运行时缓存上次选中的候选项索引。只有选择结果发生变化时才切换 bitmap，避免重复加载相同资源。

## Studio 交互

### 添加和图层

顶部“添加元素”增加“动态图片”。动态图片在图层面板中始终显示为一个普通元素，例如“天气背景”。首版不在图层面板展开候选素材。

### 公共布局

属性面板只显示一个简洁的动态素材列表。元素位置和宽高继续通过画布控制；候选素材统一强制拉伸到公共宽高。

### 动态素材列表

每个列表项包含：

- 拖拽排序手柄。
- 左侧素材缩略图。
- 中间表达式摘要。
- 右侧“编辑”按钮。

点击“编辑”打开对话框，在对话框中选择或上传素材并编辑布尔表达式。表达式编辑器下方复用现有 Token 预览控件，列出表达式引用的数据并允许修改预览值；表达式没有引用 Token 时不显示该区域。修改预览值后立即驱动画布预览和列表命中结果。

编辑已有项时对话框提供删除操作。列表底部只有一个明显的“添加素材”按钮；点击后打开同一个编辑对话框，图片保持为空，表达式复制当前列表最后一项的表达式；列表为空时使用 `false`。列表上方显示固定说明：“按从上到下的顺序匹配，只显示第一个符合条件的素材。”

Studio 根据当前模拟数据立即计算命中结果，并在列表中标记“当前命中”。修改候选顺序、表达式、素材或模拟值后重新计算。

### 隐藏时编辑

动态图片被选中时，即使当前没有命中项，也保留可选择的画框占位，避免隐藏后无法继续编辑。取消选择后按真实运行规则隐藏。

## Studio 架构与数据流

- 在元素类型联合、类型映射、插件注册和添加元素入口中注册 `dynamicImage`。
- 新增独立的动态图片 panel、renderer 和 encoder，避免把普通 `image` 改造成双模式元素。
- renderer 复用普通图片的加载和尺寸适配能力，但画布上只维护一个 Fabric 对象。命中项变化时替换该对象的图片源，不创建多个叠放对象。
- 候选表达式使用现有统一动态表达式解析、Token 预览和模拟数据能力。
- 保存前递归持久化候选素材的 `blob:` URL。
- 导出校验复用现有表达式校验能力，并把错误定位到候选项序号。

## 保存与导出校验

保存的数据保留候选项顺序。导出前必须满足：

- 至少存在一个候选项。
- 每个候选项都有唯一且非空的 `id`。
- 每个候选项都有可持久化的素材。
- 每个候选项都有合法的布尔表达式。
- `width` 和 `height` 为有效正数。

非法表达式、缺失素材或持久化失败会阻止导出，错误信息必须指出具体候选项。普通 `image` 和旧设计不做迁移，也不改变其校验规则。

## Connect IQ 构建链路

构建端新增对 `dynamicImage` 的提取与模板支持：

1. 收集全部候选素材，生成稳定且唯一的资源 ID。
2. 按数组顺序编译每个候选表达式。
3. 汇总所有表达式引用的数据字段，供运行时数据提供器生成和裁剪逻辑使用。
4. 按候选顺序执行短路匹配。
5. 只绘制最终选择的 bitmap，并强制拉伸到公共位置和尺寸。
6. 保留上次命中索引，结果没有变化时复用已选择资源。

Studio 和构建端必须共享以下契约：首个命中优先、失败继续、无结果时隐藏、素材固定拉伸到公共宽高。

## 异常处理

- 数据不可用：候选项视为不命中。
- 表达式计算异常：候选项视为不命中，不中断后续匹配。
- 候选素材加载失败：继续检查后续命中项。
- 多个表达式同时成立：按列表顺序选择第一项。
- 没有表达式成立：元素隐藏。

Studio 预览可以记录或展示非阻塞诊断信息，但上述运行时容错不能掩盖导出阶段可提前发现的配置错误。

## 测试与验收

### Studio

- 元素注册、编码、解码与保存后重新打开。
- 候选项首个命中和短路计算。
- 多个表达式同时成立时的列表优先级。
- 排序后命中结果立即变化。
- 数据不可用、表达式异常和候选素材失败后的继续匹配。
- 被选中且无匹配时保留编辑画框，取消选择后隐藏。
- 候选素材固定拉伸到公共宽高。
- 候选素材的 blob 持久化与 WRT 资源打包。
- 非法表达式和缺失素材阻止导出，并定位到具体候选项。
- 普通 `image` 与旧设计行为不变。

### Connect IQ 构建

- 提取器保留候选顺序并收集全部表达式字段。
- 生成的 Monkey C 使用首个命中优先的短路逻辑。
- 数据不可用、表达式异常和素材不可用时正确回退。
- 无候选命中时不绘制。
- 命中索引不变时不重复切换 bitmap。
- 不同设备和显示模式下资源生成与绘制正常。

### 验收场景

用一组天气背景素材创建单个动态图片：主面板只展示缩略图、表达式和编辑按钮；编辑与添加均通过对话框完成；连续添加素材时复用上一条表达式并重新选择图片；对话框底部可以调整表达式引用 Token 的预览值；多条天气表达式中即使存在重叠，也只显示列表中的第一个命中项；调整模拟天气代码后画布立即切换素材；未知天气隐藏；所有素材拉伸到相同宽高；保存、重新打开并构建 PRG 后，设备运行结果与 Studio 预览一致。
